## Run / Запуск

Use Python 3.10 or later for the k teaching lab, and Python 3.12 or later with
the tested package versions for p and s. Run from this package's root unless
the commands below change directory. Create your own virtual environment and
install requirements.txt where nonempty.

```
python revision2/code/foundations.py
python revision2/code/rc_practicum.py all
```

For the k package, `my_results` must be a new directory. No external packages
are required for its selected core exercises. Read the source README for the
biological feature table's provenance and interpretation.
